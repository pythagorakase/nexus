## Independent SQL

```sql
SELECT r.chunk_id, array_agg(c.name ORDER BY c.id)
FROM chunk_character_references r
JOIN characters c ON c.id = r.character_id
WHERE r.chunk_id = ANY(%s) AND r.reference = 'present'
GROUP BY r.chunk_id;
```

The parameter is the last 20 IDs from `SELECT id FROM narrative_chunks ORDER BY id DESC LIMIT 20`. The reader retains stored names and kind-specific IDs; Orrery spine IDs are attached separately. `transitioning` represents the wire's transit places. `referenced` means mentioned-only; `all_references` supplies coverage, maturation, and recency consumers.
