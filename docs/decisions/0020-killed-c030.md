# 0020: Let Revelations Recast Earlier Scenes

**Kind:** decision
**Links:** #849

## Ruling

Not adopted. The three-angle verification of the 2026-09-04 brainstorm killed this cluster; #849 records it.

Source: https://github.com/pythagorakase/nexus/issues/849.

> **Amendment / carry-forward:** Do not join revelations to scenes by entity/place co-occurrence. First introduce an explicit, commit-validated `claim_scene_evidence` relation authored with evidence, or restrict UI links to exact acquisition, reveal, and verified source scenes; require a populated entitlement-gated corpus before reconsidering broader marks.
